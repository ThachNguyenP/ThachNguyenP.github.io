Series này dạy Go (Golang) từ con số 0, bằng cách **xây một hệ thống thật** từ dòng lệnh đầu tiên tới lúc deploy: **Pulse**, công cụ giám sát website. Pulse kiểm tra các URL định kỳ, lưu lịch sử vào PostgreSQL, tính uptime, báo Telegram khi web sập, và có trang status công khai cho khách hàng xem. Mỗi bài thêm một tính năng và dạy đúng phần Go cần cho tính năng đó. Không bài nào chỉ nói lý thuyết suông.

Bạn cần biết trước: một ngôn ngữ lập trình bất kỳ ở mức cơ bản (biến, hàm, vòng lặp, mảng), biết dùng terminal, và biết HTTP là gì. Không cần biết Go. Đã làm Ruby, Node hay PHP thì càng dễ: tôi sẽ so sánh với những gì bạn đã quen.

#### Go là gì và dùng ở đâu
Go là ngôn ngữ do Google tạo năm 2009 cho một việc cụ thể: viết **phần mềm chạy trên server** mà nhanh, ít tốn tài nguyên, và nhiều người cùng làm không rối. Bạn dùng Go hằng ngày mà không biết: Docker, Kubernetes, Terraform, Prometheus, Grafana, CockroachDB, Caddy, phần lớn hạ tầng cloud đều viết bằng Go. Ở Đông Nam Á, các backend kiểu Grab, Shopee, Tiki, các công ty fintech, và gần như mọi đội "platform" hay "infra" đều có Go.

Go hợp với 4 loại việc:
- **API và microservice** chịu tải lớn: hàng chục nghìn kết nối cùng lúc trên một máy nhỏ.
- **Worker chạy nền**: crawler, job xử lý hàng đợi, bot, hệ thống giám sát (chính là Pulse).
- **Công cụ dòng lệnh** (CLI): một file chạy được, copy sang máy nào cũng chạy.
- **Hạ tầng**: proxy, gateway, agent thu log, plugin cho Kubernetes.

So với Ruby hay Node mà bạn có thể đã quen:

| | Ruby / Node | Go |
|---|---|---|
| Chạy | Trình thông dịch, cần cài runtime trên server | **Biên dịch** ra một file binary, chạy không cần cài gì |
| Kiểu dữ liệu | Động, lỗi kiểu phát hiện lúc chạy | **Tĩnh**, lỗi kiểu phát hiện lúc biên dịch |
| Chạy song song | Thread bị GVL (bài 101) hoặc event loop một luồng (bài 044) | **Goroutine**: hàng nghìn tác vụ song song, chạy trên mọi lõi CPU |
| Khởi động | Vài giây (Rails) | Vài mili giây |
| Bộ nhớ | Vài trăm MB cho một app | Vài chục MB |
| Thư viện | Gem, npm, rất nhiều | Thư viện chuẩn rất đầy đủ, ít cần thư viện ngoài |
| Cú pháp | Ngắn, nhiều "phép màu" | Dài hơn, **không có phép màu**, đọc code là hiểu |

Điểm cuối cùng là điều người mới hay bất ngờ nhất. Go cố tình ít tính năng: không có class, không có exception, generics chỉ ở mức vừa đủ (có từ 1.18), không có 5 cách viết một vòng lặp. Đổi lại, code của người khác viết nhìn y như code bạn viết, và một dự án 100 nghìn dòng vẫn đọc được.

#### Cài đặt Go
**macOS**
```sh
brew install go
```
**Windows**: tải file <mark>.msi</mark> ở [go.dev/dl](https://go.dev/dl/), chạy, bấm Next tới hết. Mở lại terminal (PowerShell hoặc Windows Terminal) sau khi cài.

**Linux**: tải tarball ở go.dev/dl rồi
```sh
sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.26.0.linux-amd64.tar.gz
echo 'export PATH=$PATH:/usr/local/go/bin:$HOME/go/bin' >> ~/.bashrc
source ~/.bashrc
```
Kiểm tra
```sh
go version
# go version go1.27.3 darwin/arm64
```
Thấy số phiên bản là xong. Nếu bạn từng đọc tài liệu cũ nói về <mark>GOPATH</mark>, quên nó đi: từ Go 1.11 có **Go modules**, dự án đặt ở bất kỳ đâu trên máy, không cần cấu hình gì.

**VS Code**: cài extension tên **Go** (của Go Team at Google). Lần đầu mở file <mark>.go</mark> nó hỏi cài thêm công cụ (<mark>gopls</mark>, <mark>dlv</mark>...), bấm Install All. Từ đó bạn có gợi ý code, nhảy tới định nghĩa, báo lỗi ngay khi gõ, và **tự format khi lưu**. Go có đúng một kiểu format là <mark>gofmt</mark>, không tranh cãi tab hay space, không file cấu hình Prettier.

#### Bước 1: Tạo module
```sh
mkdir pulse && cd pulse
go mod init github.com/thachnguyenp/pulse
```
Lệnh này tạo file <mark>go.mod</mark>:
```
module github.com/thachnguyenp/pulse

go 1.26.0
```
<mark>go.mod</mark> giống <mark>package.json</mark> hoặc <mark>Gemfile</mark>: khai báo tên dự án và các thư viện nó dùng. Hai điều cần hiểu:
- **Module path** <mark>github.com/thachnguyenp/pulse</mark> chỉ là một cái tên. Quy ước là đặt theo URL repo để sau này người khác <mark>go get</mark> được, nhưng không bắt buộc phải tồn tại trên GitHub. Bạn thay bằng tên của mình cũng được, nhưng nhớ thay luôn trong các dòng <mark>import</mark> ở bài 153 trở đi.
- Dòng <mark>go 1.26.0</mark> là phiên bản ngôn ngữ tối thiểu, không phải phiên bản bạn đang cài. Máy có Go 1.27 vẫn build được.

#### Bước 2: Hello world
Tạo <mark>main.go</mark>
```go
package main

import "fmt"

func main() {
	fmt.Println("Xin chào, Pulse!")
}
```
```sh
go run .
# Xin chào, Pulse!
```
Ba thứ bắt buộc của mọi chương trình Go:
- <mark>package main</mark>: file này thuộc package tên <mark>main</mark>. Package là đơn vị tổ chức code của Go (giống module trong Ruby hay thư mục trong Node); <mark>main</mark> là package đặc biệt, nghĩa là "cái này chạy được".
- <mark>import "fmt"</mark>: dùng package <mark>fmt</mark> (format) của thư viện chuẩn để in ra màn hình. Import mà không dùng là **lỗi biên dịch**, không phải cảnh báo. Go không cho code thừa.
- <mark>func main()</mark>: điểm bắt đầu. Chương trình chạy từ đây, hàm này xong là chương trình tắt.

Dấu <mark>.</mark> trong <mark>go run .</mark> nghĩa là "package ở thư mục hiện tại".

#### Bước 3: Chương trình thật đầu tiên
Hello world không dạy được gì. Thay <mark>main.go</mark> bằng phiên bản đầu tiên của Pulse: nhận một URL, gọi vào, cho biết nó sống hay chết và mất bao lâu.
```go
// main.go
package main

import (
	"fmt"
	"net/http"
	"os"
	"time"
)

func main() {
	if len(os.Args) < 2 {
		fmt.Println("Cách dùng: pulse <url>")
		os.Exit(1)
	}
	url := os.Args[1]

	client := http.Client{Timeout: 5 * time.Second}

	start := time.Now()
	resp, err := client.Get(url)
	if err != nil {
		fmt.Println("DOWN", url, err)
		os.Exit(1)
	}
	defer resp.Body.Close()
	elapsed := time.Since(start)

	fmt.Println("UP", url, resp.StatusCode, elapsed.Round(time.Millisecond))
}
```
Chạy thử
```sh
go run . https://google.com
# UP https://google.com 200 2.446s

go run . https://example.com
# UP https://example.com 200 218ms

go run . http://localhost:9
# DOWN http://localhost:9 Get "http://localhost:9": dial tcp [::1]:9: connect: connection refused
# exit status 1

go run .
# Cách dùng: pulse <url>
# exit status 1
```
25 dòng, nhưng chứa gần hết những thói quen cơ bản của Go. Đi từng dòng:

**Import nhiều package** viết trong ngoặc, mỗi dòng một package. <mark>net/http</mark> là HTTP client và server, <mark>os</mark> là tương tác với hệ điều hành (tham số dòng lệnh, file, biến môi trường), <mark>time</mark> là thời gian. Cả 4 đều là thư viện chuẩn, không phải cài gì.

**<mark>os.Args</mark>** là slice (mảng) chứa tham số dòng lệnh. <mark>os.Args[0]</mark> là tên chương trình, <mark>os.Args[1]</mark> là tham số đầu tiên. Thiếu tham số thì in hướng dẫn và <mark>os.Exit(1)</mark>: thoát với mã lỗi 1, để script gọi Pulse biết nó thất bại.

**<mark>url := os.Args[1]</mark>**: dấu <mark>:=</mark> vừa khai báo biến vừa gán, Go tự suy ra kiểu (ở đây là <mark>string</mark>). Đây là cách khai báo bạn sẽ dùng 90% thời gian. Cách dài là <mark>var url string = os.Args[1]</mark>, chỉ dùng khi cần khai báo trước mà chưa có giá trị. Biến khai báo mà không dùng cũng là **lỗi biên dịch**.

**<mark>client := http.Client{Timeout: 5 * time.Second}</mark>**: tạo một HTTP client có thời gian chờ tối đa 5 giây. <mark>http.Client</mark> là một **struct** (bài 151 nói kỹ), cú pháp <mark>Tên{Trường: giá trị}</mark> tạo một giá trị của struct đó. <mark>5 * time.Second</mark> là kiểu <mark>time.Duration</mark>: Go không dùng số giây trần như Ruby, bạn luôn ghi rõ đơn vị, nên không bao giờ nhầm 5 giây với 5 mili giây.

Đây là bài học production đầu tiên: tài liệu Go có hàm <mark>http.Get(url)</mark> ngắn gọn hơn, nhưng nó **không có timeout**. Một server đối phương nhận kết nối rồi im lặng, chương trình của bạn treo mãi mãi. Trong Pulse, một site bị treo sẽ làm toàn bộ việc giám sát đứng lại. Hầu hết lỗi "service bị treo lúc 3 giờ sáng" trong các team Go mới là do <mark>http.Get</mark> hoặc <mark>http.Client{}</mark> không có timeout. Luôn tự tạo client và đặt <mark>Timeout</mark>.

**<mark>resp, err := client.Get(url)</mark>**: hàm Go có thể trả về **nhiều giá trị**, và quy ước là giá trị cuối cùng là lỗi. Go **không có exception**. Không có <mark>try/catch</mark>, không có <mark>rescue</mark>. Hàm nào có thể thất bại thì trả về một giá trị kiểu <mark>error</mark>, thành công thì <mark>err</mark> là <mark>nil</mark> (giống <mark>null</mark>). Bạn kiểm tra ngay sau khi gọi:
```go
if err != nil {
	// xử lý lỗi, thường là trả về hoặc thoát
}
```
Người mới thấy dòng này lặp đi lặp lại và khó chịu. Sau vài tuần bạn sẽ thấy ngược lại: nhìn vào bất kỳ hàm nào cũng biết **chính xác chỗ nào có thể thất bại và nó được xử lý thế nào**, không có exception bay từ 10 tầng dưới lên. Lỗi là giá trị bình thường, truyền đi, so sánh, bọc thêm thông tin được (bài 151).

**<mark>defer resp.Body.Close()</mark>**: <mark>defer</mark> nghĩa là "chạy dòng này khi hàm hiện tại kết thúc", dù kết thúc bằng cách nào. Body của HTTP response là một kết nối mạng đang mở, phải đóng, nếu không chương trình chạy lâu sẽ hết kết nối. Viết <mark>defer</mark> ngay dưới dòng mở là thói quen bắt buộc: mở gì, <mark>defer</mark> đóng cái đó ngay dòng dưới, rồi mới viết tiếp. Giống <mark>ensure</mark> trong Ruby hay <mark>finally</mark>, nhưng gọn hơn vì đặt cạnh nơi mở tài nguyên.

**<mark>time.Now()</mark> và <mark>time.Since(start)</mark>**: đo thời gian. <mark>elapsed.Round(time.Millisecond)</mark> làm tròn để in cho đẹp (<mark>218ms</mark> thay vì <mark>218.357291ms</mark>).

**<mark>fmt.Println</mark>** in các giá trị cách nhau bằng dấu cách, xuống dòng cuối. Go biết in mọi kiểu: số, chuỗi, <mark>time.Duration</mark>, cả <mark>error</mark>.

#### Bước 4: Build ra một file
```sh
go build -o pulse .
ls -la pulse
# -rwxr-xr-x  1 nolan  staff  8334178 Nov  4 23:15 pulse
./pulse https://example.com
# UP https://example.com 200 231ms
```
<mark>go build</mark> tạo file <mark>pulse</mark> (trên Windows là <mark>pulse.exe</mark>) khoảng 8MB. File này chứa **mọi thứ**: code của bạn, thư viện chuẩn, cả runtime của Go. Copy nó sang máy khác cùng hệ điều hành là chạy, máy đó không cần cài Go. Đây là lý do CLI tool thường viết bằng Go: không có "cài Ruby 3.2 trước đã", không có <mark>node_modules</mark> 200MB.

<mark>go run .</mark> thực chất cũng build như vậy vào thư mục tạm rồi chạy. Lúc dev dùng <mark>go run</mark>, lúc giao hàng dùng <mark>go build</mark>. Bài 163 sẽ build cho Linux ngay trên máy Mac bằng cách đổi hai biến môi trường.

Thêm <mark>.gitignore</mark> để không commit binary:
```
# .gitignore
pulse
pulsed
*.exe
.env
```

#### Hai lệnh dùng hằng ngày
```sh
go fmt ./...
go vet ./...
```
<mark>go fmt</mark> format toàn bộ code theo chuẩn duy nhất của Go (VS Code đã làm sẵn khi lưu). <mark>go vet</mark> tìm lỗi mà trình biên dịch bỏ qua: in sai định dạng, gọi hàm mà bỏ quên giá trị trả về quan trọng, copy nhầm mutex... Chạy <mark>go vet</mark> trước mỗi lần commit, bài 161 sẽ đưa nó vào CI. <mark>./...</mark> nghĩa là "thư mục này và mọi thư mục con".

#### Mẹo và lỗi hay gặp
- **<mark>"fmt" imported and not used</mark>** hoặc **<mark>declared and not used: x</mark>**: Go từ chối biên dịch khi có import hoặc biến thừa. Xóa đi là xong. VS Code với extension Go tự thêm và tự xóa import khi lưu, rất ít khi bạn phải gõ import bằng tay.
- **Gõ <mark>go run main.go</mark> thay vì <mark>go run .</mark>**: hôm nay giống nhau, nhưng từ bài 151 package có nhiều file, <mark>go run main.go</mark> sẽ báo thiếu hàm. Quen dùng <mark>.</mark> từ đầu.
- **Chữ hoa chữ thường có ý nghĩa**: <mark>fmt.Println</mark> viết hoa P. Trong Go, tên bắt đầu bằng chữ hoa là **public** (dùng được từ package khác), chữ thường là **private**. Không có từ khóa <mark>public</mark>/<mark>private</mark>, chỉ có chữ cái đầu. Bài 153 sẽ dùng điều này.
- **Dấu ngoặc nhọn mở phải cùng dòng** với <mark>func</mark>, <mark>if</mark>, <mark>for</mark>. Đặt xuống dòng dưới là lỗi cú pháp, không phải phong cách. <mark>gofmt</mark> cũng không sửa được cái này cho bạn.
- **<mark>exit status 1</mark>** sau khi in DOWN không phải lỗi của <mark>go run</mark>: nó chỉ báo chương trình của bạn đã thoát với mã 1 như bạn yêu cầu.

- <mark>go version</mark> in ra 1.26 trở lên.
- <mark>go run . https://example.com</mark> in <mark>UP</mark>, mã 200 và thời gian.

- Cho phép truyền nhiều URL: <mark>os.Args[1:]</mark> là slice từ phần tử 1 tới hết, lặp qua bằng <mark>for _, url := range os.Args[1:] { ... }</mark>. Bài sau sẽ làm đúng việc này, nhưng với file danh sách.

Bài tiếp theo: đọc danh sách URL từ file, in bảng kết quả, xuất JSON và CSV, và học struct, slice, map, cách Go xử lý lỗi.
