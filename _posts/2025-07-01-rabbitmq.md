# Introduction to RabbitMQ Queues: Installation, Setup, Usage, and Demo with ReactJS & Ruby on Rails

RabbitMQ is a popular open-source message broker that enables applications to communicate asynchronously using queues. It’s widely used for building scalable, distributed systems.

## What is RabbitMQ?

RabbitMQ implements the Advanced Message Queuing Protocol (AMQP), allowing producers to send messages to queues, and consumers to process them. This decouples your services, improves reliability, and enables background processing.

## Installing RabbitMQ on Mac

You can install RabbitMQ easily using Homebrew:

```bash
brew update
brew install rabbitmq
```

After installation, start RabbitMQ:

```bash
brew services start rabbitmq
```

To check if RabbitMQ is running, visit [http://localhost:15672](http://localhost:15672) (the management UI). Default credentials are `guest`/`guest`.

## Setting Up RabbitMQ

1. **Enable the Management Plugin:**

   ```bash
   rabbitmq-plugins enable rabbitmq_management
   ```

2. **Create a User (Optional):**

   ```bash
   rabbitmqctl add_user myuser mypassword
   rabbitmqctl set_user_tags myuser administrator
   rabbitmqctl set_permissions -p / myuser ".*" ".*" ".*"
   ```

3. **Configure Queues and Exchanges:**
   - You can use the management UI or configure via code (see demo below).

## Usage Tips

- **Durable Queues:** Make queues durable to survive broker restarts.
- **Prefetch Count:** Set prefetch for consumers to control message load.
- **Dead Letter Exchanges:** Use DLX for failed messages.
- **Monitoring:** Use the management UI for monitoring queues and consumers.

## Demo: ReactJS Frontend & Ruby on Rails Backend

Let’s build a simple demo where ReactJS sends a message to Rails, which enqueues it in RabbitMQ.

### 1. Ruby on Rails: Sending Messages to RabbitMQ

Add the `bunny` gem to your Rails app:

```ruby
# Gemfile
gem 'bunny'
```

Install gems:

```bash
bundle install
```

Send a message to RabbitMQ:

```ruby
# app/controllers/messages_controller.rb
require 'bunny'

class MessagesController < ApplicationController
  def create
    connection = Bunny.new
    connection.start
    channel = connection.create_channel
    queue = channel.queue('demo_queue', durable: true)
    queue.publish(params[:message])
    connection.close
    render json: { status: 'Message sent' }
  end
end
```

### 2. ReactJS: Sending Messages to Rails

Create a simple form:

```jsx
// src/App.jsx
import React, { useState } from 'react';

function App() {
  const [message, setMessage] = useState('');

  const sendMessage = async () => {
    await fetch('http://localhost:3000/messages', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ message }),
    });
    alert('Message sent!');
  };

  return (
    <div>
      <h1>Send Message to RabbitMQ</h1>
      <input value={message} onChange={e => setMessage(e.target.value)} />
      <button onClick={sendMessage}>Send</button>
    </div>
  );
}

export default App;
```

### 3. Consuming Messages in Rails

Add a simple consumer:

```ruby
# lib/consumer.rb
require 'bunny'

connection = Bunny.new
connection.start
channel = connection.create_channel
queue = channel.queue('demo_queue', durable: true)

puts 'Waiting for messages...'
queue.subscribe(block: true) do |_delivery_info, _properties, body|
  puts "Received: #{body}"
end
```

Run the consumer:

```bash
ruby lib/consumer.rb
```

## Conclusion

RabbitMQ is a powerful tool for building scalable, asynchronous applications. With simple setup and integration, you can decouple your frontend and backend, improve reliability, and handle background tasks efficiently.

**Tips:**
- Always monitor your queues.
- Handle message failures gracefully.
- Secure your RabbitMQ instance in production.
